== launch help

pcsxroo - drive the PCSXROO debugger from the command line



usage: pcsxroo [global flags] <group> <verb> [arguments]



global flags:

  --port N          debug server port (default 28110, or $PCSXROO_PORT)

  --host H          default 127.0.0.1

  --cpu ee|iop      which CPU to address (default ee)

  --json            print the raw JSON reply instead of a rendered one

  --timeout MS      wait, step, pause and frame-advance: the command's own time limit

                    (defaults 60000, 5000, 2000, 10000). Any other command: give up

                    after MS with no reply. Without it the server's own limits apply.

  --help, -h        this text



starting up:

  launch [game] [--bios] [--pause-on-entry] [--emulator PATH]

                                   [--ready-timeout MS]

                                   start the emulator; with no game it comes up

                                   idle with the server listening and no VM

  boot <game>                      boot a game in an emulator already running

  boot --bios                      boot the PS2 BIOS with no disc

  boot --elf PATH                  boot an ELF directly

      all accept [--pause-on-entry] [--fast-boot]



session:

  version                          emulator, PCSX2 base revision, protocol

  status                           VM state, PCs, game identity, last stop

  wait [--since N]                 block until a stop newer than N

  events                           stream stop events until interrupted
